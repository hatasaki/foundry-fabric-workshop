# 受講者ガイド — 浜松第2ラインの出荷判断

[ワークショップトップ](../../README.md) · [English](../en/README.md)

架空の精密アクチュエータメーカーで、真空ろう付け炉 `EQ-VBF-204` の異常と、磁石ロット `LOT-MAG-088` の品質保留が発生しました。営業のERPリストから漏れたリスクがないかを調べ、決裁者、初動8D（品質問題の初動報告）の期限、封じ込めと代替手段を説明します。使用するデータは **2026年5月14日** のスナップショットです。

講師が用意するのは、研修アカウント、空の Fabric ワークスペース、親 Foundry リソース、モデル、共通 Azure AI Search です。**Lab 00 から順に進めます。** `studentN` は Lab 00 で Azure ポータルから自分で新規作成し、Foundry ポータルで開くのは Lab 04 です。Lab 01・02・04・05 では、手順で指定された項目や接続を新規作成します。Lab 03 では Lab 02 のオントロジーを更新してグラフを構成し、Lab 06 では Lab 05 で作成したエージェントをテストします。

## 始める前に

- 講師から受講者番号、研修アカウント、Fabric ワークスペース、親 Foundry リソース、モデル、共通 Azure AI Search の情報を受け取ります。
- GitHub からリポジトリを ZIP でダウンロードするか、`git clone` で取得し、[日本語の演習データ](data/README.md)を手元に用意します。Lab 01 と Lab 04 では `jp` フォルダーから、それぞれ CSV 15本と Markdown 8本を使います。
- 画面のメニューやボタンは日本語名で記載します。新しい Foundry ポータルの **ツール**、**ナレッジ**、**エージェント** は **ビルド** の左ナビゲーションにあります。

**4時間枠：** Lab 03（15分）、Lab 05（15分）、Lab 06（20分）の発展課題と休憩10分を追加します。

**エラーや中断から再開するとき：** 自分のワークスペースやプロジェクトの項目一覧を更新し、最後に実行した操作が保存されているかを確認します。次の未完了の手順から再開します。接続先とサインイン先を確認しても権限エラーが続く場合は、操作とエラー内容を講師に伝えます。

**ゴール：** プレイグラウンド の同じ応答で Fabric IQ と Foundry IQ の取得を確認し、どの受注が増え、どの規程によって決裁判断が変わったかを説明します。締切の算定に必要な記録を確認し、判断メモに対応案と確認事項をまとめます。
