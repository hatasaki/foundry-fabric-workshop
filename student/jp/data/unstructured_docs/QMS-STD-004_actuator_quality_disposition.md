# 品質検査基準書: 精密アクチュエータ出荷・工程内不適合処置規定

- **文書ID**: `DOC-QMS-004`
- **対象製品**: `PRD-ACT-900`、`PRD-ACT-650`、`PRD-ACT-400` ほか全サーボアクチュエータ製品群
- **対象不具合コード**: `DEF-BOND-02`、`DEF-TRQ-04`、`DEF-DIM-01`
- **主管部門**: 品質保証部（改定日: 2026-01-10）

---

## 1. 主要検査特性と合否判定基準

| 検査項目 | 対象カラム | 合格基準 (`DEF-00`) | 再加工上限 (`Rework=2`) | 即時保留・廃棄判定 (`ScrapHold=3`) |
| :--- | :--- | :--- | :--- | :--- |
| トルクリップル率 | `torque_ripple_pct` | 2.0 % 以下 | 2.1 〜 3.0 % | **3.0 % 超 (`DEF-TRQ-04`)** |
| ろう付け接合ボイド面積率 | `bond_void_area_pct` | 2.0 % 以下 | 不可（接合やり直し不可） | **5.0 % 超 (`DEF-BOND-02`)** |
| 巻線絶縁抵抗 | `insulation_mohm` | 500 MΩ 以上 | 300 〜 499 MΩ（乾燥再検査） | **300 MΩ 未満 (`DEF-INS-01`)** |

## 2. `DEF-BOND-02`（接合ボイド異常）および `DEF-TRQ-04`（トルクリップル異常）の複合発生時ルール

- `bond_void_area_pct` が **5.0% 超** となった個体は、高速回転時の磁石剥離リスクがあるため再加工（Rework）を認めず、全数を `ScrapHold`（`disposition_code = 3`）として赤札隔離保管庫へ移動する。
- 同一設備または同一磁石ロット（`MAT-MAG-04`）を用いた製造指図で `DEF-BOND-02` と `DEF-TRQ-04` が両方検出された場合、**設備側の真空・温度異常と部材ロット側の吸湿・保磁力低下の複合要因**として扱い、同一設備×同一部材ロットで製造中の全製造指図（ERP上の受注ステータスがまだ `InProduction=2` のまま更新されていないものを含む）を横断抽出して出荷停止ロックをかけること。
- 顧客への特別採用（Concession）申請は `Tier1` 顧客では原則不可であり、良品ロット（代替部材ロットおよび健全設備で再製造したもの）での納入のみ認められる。
