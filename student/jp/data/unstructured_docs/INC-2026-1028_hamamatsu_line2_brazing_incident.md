# 過去インシデント調査報告書（8D記録）: 浜松第2ライン VBF-204 真空シール劣化と接合ボイド事象

- **文書ID**: `DOC-INC-1028`
- **事象発生日**: 2026-02-28（恒久対策登録日: 2026-03-05）
- **対象拠点・設備**: 浜松精密工場 `LINE-HMM-02` / `EQ-VBF-204`
- **主管部門**: 品質保証部・浜松製造課

---

## 1. 事象概要と根本原因（Root Cause）

2026年2月末、`EQ-VBF-204` にて `ALT-VAC-LEAK`（ピーク 8.2 Pa）が発生した際、現場判断でアラートをリセットして運転を継続した結果、後続ロットで接合ボイド率 6% 超（`DEF-BOND-02`）が発生した。

分解調査の結果、以下の複合要因が確認された。
1. 前回校正・シール点検から 90日を超過しており、フランジOリング（`PART-SEAL-KF40-VT`）に熱硬化クラックが生じていた。
2. 投入された磁石ロットの吸湿量が高めであったため、昇温時のアウトガス負荷が増大し、排気ポンプ能力を超過してチャンバー圧力が 5.0 Pa を突破した。

## 2. 教訓とオントロジー／監視ルールへの反映事項

- ERPの受注画面（`erp_sales_orders`）のステータスは夜間バッチまたは生産管理担当者の手動更新まで `InProduction (2)` のまま残るため、**ERP単体を見ているだけでは現場の `QualityHold (30)` による納期遅延リスクを即座に検知できない**。
- 設備アラート（IoT）→ 設備・製造指図・部材ロット（MES）→ 製品・顧客受注（ERP）をグラフ関係で常時たどれるようにし、**未更新のERP受注（隠れリスク案件）も含めて影響範囲を即時特定する運用**を標準化すること。
