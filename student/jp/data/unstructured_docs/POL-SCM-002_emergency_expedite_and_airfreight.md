# サプライチェーン緊急対応ポリシー: 代替調達・工場間振替・緊急チャーター/空輸承認規定

- **文書ID**: `DOC-POL-SCM002`
- **対象業務**: `Tier1` 顧客向け受注（`erp#Order`）の納期遅延リスク（`AtRisk` または工程内 `ScrapHold` 波及）発生時の緊急対応
- **主管部門**: SCM本部・経営企画部（改定日: 2025-11-01）

---

## 1. エスカレーション発動条件

以下のいずれかに該当する場合、出荷予定日（`promised_ship_date`）の **5営業日前まで** に緊急対策会議（SCM・製造・品質・営業合同）を招集し、代替生産および緊急輸送の採否を決定しなければならない。

1. ERP受注ステータスが `AtRisk`（コード `3`）となった `Tier1` 顧客受注。
2. ERP受注ステータスが `InProduction`（コード `2`）であっても、紐づく MES 製造指図（`mes#Order`）が `QualityHold`（コード `30`）または検査判定 `ScrapHold`（コード `3`）となり、良品数量（`good_qty`）が受注数量（`order_qty`）に対して不足する案件。

## 2. 緊急対策オプションの優先順位

1. **第1優先（工場間ライン振替）**: 同一社内拠点の健全設備（例: 浜松 `EQ-VBF-204` 停止時は名古屋 `EQ-VBF-205`）の空き枠および認定済み健全在庫ロット（例: `LOT-MAG-091`）を引き当てて緊急追加工番を発行する。
2. **第2優先（認定バックアップサプライヤーへの緊急発注）**: 主サプライヤーの品質保留時は、`is_qualified_backup = true` の認定済み代替サプライヤー（例: `MAT-MAG-04` の場合は `SUP-007` 信州マグネットマテリアルズ）へ緊急スポット発注または輸送中POの前倒し納入を要請する。
3. **第3優先（緊急チャーター便・航空便手配）**: 通常トラック便で納入期日に間に合わない場合、専用チャーター便または国内航空貨物便を手配する。

## 3. 緊急費用・特別手配の決裁権限マトリクス（重要）

影響を受ける対象受注の**合計受注金額（`order_amount_jpy`）**および**緊急追加費用見積額**に応じて、以下の決裁承認を取得すること。

| 対象受注金額規模 または 追加手配費用 | 最終決裁権限者 | 必須添付エビデンス |
| :--- | :--- | :--- |
| 対象受注合計 **3,000万円未満**（かつ追加費用 100万円未満） | **工場長（Plant Manager）** | 製造指図遅延明細・代替ライン日程表 |
| 対象受注合計 **3,000万円以上 〜 9,000万円未満**（かつ追加費用 300万円未満） | **SCM本部長（VP of Supply Chain）** | 上記 ＋ SLA遅延違約金との損益比較試算表 |
| 対象受注合計 **9,000万円以上**（または追加費用 300万円以上） | **COO（最高執行責任者）決裁** | 上記 ＋ 全波及顧客リスト・8D初動ドラフト・品質保証部長合議書 |

> **損益判断ルール**: 1日あたりの顧客SLA遅延違約金合計（`sla_penalty_jpy_per_day` の合算）× 想定遅延日数が、緊急チャーター・残業追加費用を上回る場合は、原則として緊急手配を承認する。
